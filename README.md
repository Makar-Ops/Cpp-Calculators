# Cpp-Calculators
2 calculators in C++: Default and with a history
This is my first project on GitHub.  
I wrote 2 simple calculators in C++:

1. **Default calculator** — supports basic operations: `+`, `-`, `*`, `/`
2. **Calculator with history** — saves all your calculations and shows them on request

---

## 🛠️ How to run

### Default calculator
```bash
g++ calc.cpp -o calc.exe
./calc.exe
